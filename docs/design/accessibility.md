# Доступность

Цель — WCAG 2.2 AA и рекомендации Android по доступности. Правила ниже встроены в токены и
компоненты, а не остаются на совести экранов; то, что можно проверить машиной, проверяется.

## Контраст

* **102 пары** «текст/фон» и «элемент/фон» в обеих темах: текст ≥ 4.5:1 (1.4.3), контуры, иконки,
  выбранные состояния, фокус ≥ 3:1 (1.4.11). Проверяет генератор токенов (сборка падает) и
  `DesignSystemResourcesTest` на готовых Android-ресурсах. Полный отчёт — в
  [`tokens/README.md`](tokens/README.md#контраст-wcag-22-aa).
* Инициалы на всех семи цветах палитры аватаров — ≥ 4.5:1 в обеих темах.
* Текст поверх фото — только белый на `photoScrim` (55–60 % чёрного); кнопки поверх фото — на
  собственной полупрозрачной подложке. Акцент поверх фото не используется.
* Отключённые элементы (38 %/12 %) освобождены от требования контраста по WCAG, но всегда
  сопровождаются объяснением, почему действие недоступно, если причина не очевидна.

## Не только цветом (1.4.1)

| Состояние | Кроме цвета |
|---|---|
| Выбранный фильтр-чип | инверсная заливка вместо контура |
| Выбранная вкладка навигации | пилюля-индикатор и залитая иконка |
| Лайк | залитое сердце вместо контурного |
| Выбранная вещь | рамка 2 dp и галочка |
| Ошибка поля | текст ошибки под полем |
| Fit score, статусы очереди | число и иконка в бейдже |
| Непрочитанное | число в счётчике, жирное имя |

## Зоны касания (2.5.8)

* Минимум **48×48 dp** для всего интерактивного. Кнопки — 48 dp высотой без инсетов; small-кнопка
  40 dp визуально + инсеты до 48; чипы 36 dp + `chipMinTouchTargetSize` 48; иконки-кнопки 48×48;
  маркер опорной точки 28 dp с зоной 48; строки списков ≥ 56 dp.
* Переключатель в строке управляется всей строкой — одна большая цель вместо маленького тумблера.
* `DesignSystemResourcesTest.interactiveComponentsMeetTouchTarget` проверяет `minHeight` всех
  интерактивных стилей по токенам.

## TalkBack и contentDescription

* Иконки-кнопки — всегда с `contentDescription` (Lint `ContentDescription` повышен до ошибки).
  Декоративные картинки (иллюстрации состояний, фото внутри карточки, у которой есть общее описание,
  аватар рядом с именем) — `importantForAccessibility="no"`.
* Составные компоненты читаются одной фразой: карточка образа — «Образ от Анны Ковалёвой. Ремикс.
  Тренч, который…»; карточка вещи — «Свитер из мериноса, Верх · слой 2».
* Роли и состояния: лайк — переключатель «Нравится. 128 отметок „Нравится“, отмечено»; выбираемая
  вещь — флажок; строка с переключателем — Switch; на Android 16 используется трёхсостояний
  `setChecked(int)` (`A11y.setChecked`).
* Жесты продублированы действиями: двойной тап по фото → действие «Нравится», комментарии →
  действие «Комментарии» (`A11y.addAction`).
* Заголовки экранов и секций — heading для навигации по заголовкам; появление ошибки, пустого
  состояния и офлайн-баннера объявляется live region.
* Счётчики и плюралы — через `plurals` с формами one/few/many/other.

## Масштаб шрифта до 200 %

* Весь текст — в **sp**, интерлиньяж тоже в sp (Android 14+ масштабирует его пропорционально).
  Литеральные размеры в разметке запрещены тестом.
* Android 14+ масштабирует нелинейно: мелкий текст растёт вдвое, крупные заголовки — мало
  (14 → 26 dp, 24 → 36, 48 → 54). Журнальная вёрстка сохраняется, а мелкое становится читаемым.
* Правила компонентов при шрифте ≥ 150 % (`A11y.isLargeFontScale`):
  * нижняя навигация — только иконки (`NavigationBars.applyDesignSystemRules`), названия — в
    подсказке и для TalkBack;
  * табы — прокрутка вместо сжатия (`tabMode="auto"`);
  * имя автора и мета в карточке — до двух строк;
  * кнопки — подпись до двух строк, кнопка растёт; ряды кнопок встают друг под другом;
  * раскладки «рядом» (превью + поле, аватар + счётчики) становятся «друг под другом».
* Сообщения `StateView` прокручиваются, строки списков растут по высоте, ничего не обрезается
  фиксированной высотой.
* На каждой доске экранов в [`screens.md`](screens.md) есть вариант со шрифтом 200 %; значения
  размеров — по нелинейной таблице Android 14 (генерируются в CSS из токенов).

## Движение и вестибулярный комфорт

* «Убрать анимации» выключает движение компонентов (см. [`motion.md`](motion.md#убрать-анимации-и-масштаб-анимаций)),
  параллакса и автопрокрутки нет, мигания нет.
* Хаптика — через `performHapticFeedback`, поэтому уважает системную настройку.

## Прочее

* Тёмная тема — своя (не `forceDark`), с собственной проверкой контраста.
* RTL: отступы `start/end`, направленные иконки зеркалируются, блик скелетона идёт в обратную
  сторону, точка «в сети» — у нижнего «конечного» угла.
* Ошибки — человеческим языком с причиной и действием («Проверьте подключение и попробуйте ещё
  раз» + «Повторить»), без кодов.
* Время на действие: окно «Отменить» 5 с, с TalkBack — дольше (рекомендация системы).

## Чек-лист экрана

- [ ] Все цвета — семантические токены; нет HEX и литеральных dp/sp в разметке.
- [ ] Все интерактивные элементы ≥ 48 dp; у иконок-кнопок есть описание.
- [ ] Спроектированы состояния: загрузка, пусто, ошибка сети с «Повторить», офлайн, нет прав.
- [ ] Экран проверен со шрифтом 200 %, в тёмной теме и с TalkBack (порядок фокуса, заголовки).
- [ ] Жесты продублированы кнопками или доступными действиями.
- [ ] Выбранные и ошибочные состояния различимы не только цветом.
